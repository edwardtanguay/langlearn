	- mots qui se terminent par -er = "AY"
		- parler, premier, danger, le dernier moment
		- mais les exceptions: hier, la mer, le fer
	- les lettres "e"
		- e = [uh]
		- é,-er = [ay]
		- è/ê = [eh]
	- les lettres "a"
		- toujour [AH]
			- Paris = PAH-ree
			- "La tata de Clara a quatre chats"
	- "i" et "u" sont très similaire
	- les consonnes finales
		- en général, on ne prononce pas les consonnes finales
		- les exceptions sont les mots qui se terminent par: CRFL (so be CaReFuL)
			- avec, un sac (mais: estomac [MAH])
			- un chef, un oeuf
			- la mer, le fer, finir, choisir (mais -er es toujour [AY])
			- le miel, le sel (mais: un outil et gentil [TEE])
		- note : "but" [bü] (sans "t" aussi quand Google Translate prononce le lettre "t")
		- exception : tous, plus
			- [TOOS], ils sont tous venus me voir
				- exception: il travaille tous les jours
			- [PLOOS]
				- Il a plus de temps. [PLOOS]
				- Il n'a plus de temps. [PLOO]
					- Il est plus professionnel que moi
	- "s"
		- régionalisme [EES-mah]
	- sons qui disparaissent
		- samedi = [samdi]
		- je sais = [shay]
		- je suis = [shwee]
		- tu as vu ce film? = [tah vü]
		- je ne sais pas = [je sais pas] = [shay pah]
		- je ne suis pas dispo = [shwee pah]
		- cinéma = ciné
		- association = asso
		- restaurant = restau
	- vocabulaire informal
		- une voiture = une caisse
		- une maison = une baraque
		- une femme = une meuf, une nana
	- le verlan
		- j'ai maté une série, j'ai rien pigé à l'histoire
		- ce mec là-bas, il est chelou

- placement des pronoms
	- le pronom d'objet direct (le) se place avant le pronom d'objet indirect de la troisième personne (lui)
		- il lui donne le livre -> il le lui donne
		- tu rends le livre à ta soeur? -> oui, je le lui rends
		- tu ne les lui donnes pas

- La place des adjectifs en français
	- https://parlez-vous-french.com/la-place-des-adjectifs-en-francais
	- avant le nom
		- adjectifs numéraux cardinaux
			- dix élèves
		- adjectifs ordinaux
			- notre première réunion
		- adjectifs courts et fréquents
			- une vraie surprise
			- un mauvais garçon
			- ce jeune homme
	- après le nom
		- adjectifs qui indiquent une description : couleur, nationalité, style, goût, catégorie, d'apparence
			- la langue française 
			- une cathédrale gothique
		- adjectifs verbaux
			- un enfant abandonné
		- adjectifs dérivés d'un nom
			- une piscine municipale
		- adjectifs de trois syllabes ou plus
			- un vélo électrique
		- adjectifs qui indiquent une notion de temps
			- le mois dernier
	- avant ou après le nom
		- certains adjectifs changent de sens
			- c'est un sale type
		- Les adjectifs courts et fréquents se placent après le nom quand il y a un adverbe long qui les précède.
			- Un très bel homme. => Un homme particulièrement beau.
			- Un très long discours. => Un discours incroyablement long.
		- Si l'adjectif placé avant les noms est au pluriel, l'article indéfini “des” se transforme en “de”.
			- Il y a des maisons magnifiques. => Il y a de magnifiques maisons.
			- Ce sont des pâtisseries délicieuses. => Ce sont de délicieuses pâtisseries.
		- Les adjectifs masculins “beau”, “fou”, “vieux”, “nouveau” suivis d'une voyelle se transforment en “bel”, “fol”, “vieil”, “nouvel”.
			- Un beau monsieur. => Un bel immeuble.
			- Un vieux garçon. => Un vieil homme.
			- Un nouveau logement. => Un nouvel appartement.
