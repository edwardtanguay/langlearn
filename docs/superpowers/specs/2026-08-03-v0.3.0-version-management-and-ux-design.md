# v0.3.0 - Full Version Management + Improved UX Specification

## Overview
This document specifies the technical design for release `v0.3.0` of LangLearn, implementing full version management (CRUD, categories, status badges, markdown issue export, post-save animations, and footer version links) alongside core UX improvements across Flashcards, Idea Box, Pronunciation page, Import page, Navigation Header, Profile settings, and Stats modal.

---

## 1. Version Management & Footer Design

### 1.1 Data Schema & API Updates (`prisma/schema.prisma`, `server/api/versions/*`)
- **Version Model Status Enum**: `PUBLISHED` | `IN_PROGRESS` | `FUTURE_VERSION` | `INCOMING` | `PROPOSED_ITEMS`.
- **Status Color Mapping**:
  - `FUTURE_VERSION`: Dark gray (`bg-zinc-700 text-zinc-200`)
  - `INCOMING`: Dark red (`bg-red-900 text-red-100`)
  - `IN_PROGRESS`: Yellow (`bg-yellow-600 text-yellow-100`)
  - `PUBLISHED`: Omitted from item target version assignment dropdowns in admin edit mode.
- **REST Endpoints**:
  - `GET /api/versions/public`: Returns grouped versions, categories, and unassigned incoming items.
  - `POST/PUT/DELETE /api/versions/items`: Version item CRUD operations.
  - `POST/PUT/DELETE /api/versions/categories`: Category CRUD operations.
- **Incoming Ideas Section**: Renamed from "Incoming Changes" to "Incoming Ideas". If `unassignedItems` is empty, displays:
  > *"All current ideas have been processed. Waiting for new ideas."*

### 1.2 Markdown Issue Export Modal (`app/pages/about.vue`)
- Admin button **"Create issue markdown"** triggers a modal rendering formatted issue text for the version:
  ```markdown
  # v0.3.0 - [Version Title]

  ## [Category Title]
  - BUG-FIX: [item body]
  - FEATURE: [item body]
  ```
- Includes a **"Copy to Clipboard"** button with temporary toast confirmation.

### 1.3 Post-Save Highlight Animation (`app/pages/about.vue`)
- When an admin saves an edited item, set `recentlyEditedItemId = item.id` for 1500ms.
- Target item element triggers a subtle pulse highlight (`@keyframes editHighlight { 0%: scale(1); 50%: scale(1.02); 100%: scale(1); }`).

### 1.4 Footer Version Link (`app/components/Footer.vue`)
- Anchored to bottom, horizontally centered: `<NuxtLink to="/about">v0.3.0</NuxtLink>` without underline.
- If `publishDate` is within 24 hours (`now - publishDate <= 86400000`), renders a green flag to the right: `<span class="bg-emerald-600 text-white text-xs px-1.5 py-0.5 rounded">New!</span>`.

## 2. Flashcard Page & Pronunciation Page Design

### 2.1 Flashcard Page (`app/pages/flashcard/[id].vue`, `FlashcardFront.vue`, `FlashcardBack.vue`)
- **Card Transition Smoothness**: Ensure card state updates flip smoothly without full DOM resets or URL blinking.
- **Language Flicker Cue**: On transition where `card.frontLanguage !== prevCard.frontLanguage`, trigger a 600ms keyframe animation (`languageBadgePulse`) on the 2-letter language badge using the specific target language color code.
- **"convert vous to tu" Button**: On French flashcards (`frontLanguage === 'fr'`) containing `"vous"` (case-insensitive), render a button that opens:
  `https://www.google.com/search?q=convert+%22vous%22+to+%22tu%22+for+the+following+French+phrase%3A+%22[phrase]%22` in a new tab.
- **Highlighted Text Styling**: Highlighted words render with a dashed underscore (`border-b border-dashed border-slate-300`) and a subtle background accent.
- **Pulsating Hooks & Pronunciations**: Front memory hooks and back pronunciations animate with a gentle CSS keyframe opacity pulsation when presented.
- **Brightened Pronunciation**: Styled with high contrast `#f8fafc` text color.

### 2.2 Pronunciation Page (`app/pages/pronunciation.vue`)
- **Three-Way Toggle**: Toggle state cycles through: `[0: English] -> [1: Target Language] -> [2: Pronunciation]`.
- **Last Touched First**: Query flashcards sorted by `updatedAt desc`.
- **Helpful Resources Video Link**: Header card titled *"Helpful Resources"* containing bullet:
  - `FR` (in French dark blue `#333388`): [conseils pour améliorer la prononciation du français](https://www.youtube.com/watch?v=Bmxdtrv4uQM) — *30 minutes avec des conseils sur les liaisons, etc.*
- **Front Language Badge**: Displays target language initials (e.g. `FR`) on the front of the card instead of `EN`.
- **Card Edit Link**: Permalinks click straight to `/flashcard/[id]` for editing.

## 3. Idea Box & Import Page Design

### 3.1 Idea Box (`app/components/QuickAddIdeaDrawer.vue`)
- **Rank Slider**: Range input from `0.0000` (red background gradient) to `5.0000` (green background gradient), defaulting to `2.5000`. Numbers hidden from UI.
- **Tag Colors**: `Bug-Fix` tag is `#ea580c` (orange), `Feature` tag is `#16a34a` (green).
- **Navigation Auto-Close**: Closes drawer on route change.
- **Focus & Form Submission**: Auto-focus bug fix textarea on open with thin border style. Form controls disable during submission with spinner, displaying thanks message (*"Thanks for the bug report!"* or *"Thanks for the feature request!"*).
- **Placeholders**: Updated to *"Describe a bug here..."* and *"Describe a feature request here..."*.

### 3.2 Import Page (`app/pages/import.vue`, `server/api/import.ts`, `prisma/seed.ts`)
- **Prefix Cleaning**: Remove `"my friend,"` (case-insensitive) prefix from imported English text.
- **Asterisk Removal**: Remove all `*` characters from imported front phrases.
- **Database Cleanup Script**: Run cleanup update query to strip leading/embedded `*` from existing `Flashcard` front fields.
- **Legacy UI Removal**: Remove obsolete imported text output below the main textarea.

## 4. Header, Profile & Stats Modal Design

### 4.1 Header & Daily Take Goal (`app/components/Navigation.vue`, `app/pages/profile.vue`, `prisma/schema.prisma`)
- **User Schema**: Add `dailyTakeGoal Int @default(100)` to `User` model.
- **Desktop Take-Count**: Render take-count pill on desktop header matching mobile layout.
- **First Name Display**: Show `firstName` only next to avatar icon.
- **Take-Count Progress Color**: Button color shifts from red (`< 33%`), yellow (`33-99%`), to green (`>= 100%` of `dailyTakeGoal`).
- **Celebration Mode**: When `todayCount >= dailyTakeGoal`, apply subtle dark fireworks CSS/canvas animation background to header. Resets at midnight local time.

### 4.2 Stats Modal (`app/components/Navigation.vue`, `QuickAddIdeaDrawer.vue`)
- **Mutual Exclusion**: Opening Stats modal auto-closes Idea Box drawer; opening Idea Box drawer auto-closes Stats modal.
- **Wording Update**: Change *"Got right"* to *"Learned"*.
