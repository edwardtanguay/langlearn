Create an HTML/CSS/JavaScript file called index.html in the folder dev\info-sites which displays sections each on a different topic. The topic is "Twenty towns and neighborhoods around Dijon to visit", the point is not so much to see museums, etc. but to get the feel of various parts of the town, both affluent neighborhoods and less affluent ones, and to get a feel for what it's like to live there. For each section, write a title and a short description of about 200 words in B1/B2 French. Before the text, make a drag/drop exercise where the learner can drag the most difficult vocabulary words in the text to their definitions. After the text, write one general opinion question about the topic of the section that the teacher and the student can both answer and discuss. This web page should be one long text that can be scrolled from top to bottom, with all the CSS and JavaScript inline with the HTML, no external files and no images. Make the font easy to read and the layout clear and simple.
